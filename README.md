# Deep Focus Bubble

A Chrome extension that helps you stay focused by blocking distracting websites. Create protective "focus bubbles" around the spaces that pull your attention away.

**Disclaimer**: AI has been used to generated the code for this extension and most documents here.

## Features

### Three Ways to Block Distractions

| Mode | What it does |
|------|--------------|
| **Deep Focus** | Blocks a website until you decide to unblock it |
| **Work Hours** | Blocks only during your work hours (you set the schedule) |
| **Brief Pause** | Blocks for 1 hour, then automatically unblocks |

### Other Features

- **One-click blocking** - Block any site you're viewing with a single click
- **Reflection prompts** - When you unblock a site, you're asked why (helps build awareness)
- **Unblock history** - See patterns in when and why you unblock sites
- **Clean, calming design** - No harsh warnings, just a gentle reminder to stay focused

### Manual Installation (Developer Mode)
1. Download or clone this repository
2. Open Chrome and go to `chrome://extensions/`
3. Turn on "Developer mode" (top right toggle)
4. Click "Load unpacked"
5. Select the `focus-plugin` folder
6. Done! The extension icon will appear in your toolbar

## How to Use

### Block a Website
1. Go to the website you want to block
2. Click the Focus Bubble icon in your toolbar
3. Choose how long to block it:
   - **Deep Focus** - Until you manually unblock
   - **Work Hours** - Only during work hours
   - **Brief Pause** - Just for 1 hour
4. Click "Protect This Space"

### Unblock a Website
When you try to visit a blocked site, you'll see a calming blocked page. To unblock:
1. Write a brief reason why you want to unblock (this helps you reflect)
2. Click "Return to Flow"

You can also remove sites from your Settings page without needing a reason.

### Set Your Work Hours
1. Click the extension icon → "Settings"
2. Set your start and end times
3. Click "Save"

Sites blocked with "Work Hours" mode will only be blocked during these times.
